# 博客原型本地验收记录

日期：2026-10-22。

## 已验证

- 首页页脚 Blog 位于「更多功能」之后，实际点击进入博客。
- 前台分类、搜索、排序组件及文章列表可使用，配图可加载。
- 示例文章禁用 JavaScript 后仍有标题、摘要与正文，不依赖图片承载文字。
- 后台使用真实 Jodit 4.18.7，本地加载，无 CDN 依赖。
- 编辑、双栏表格、提示框、素材插入、视频地址嵌入和封面选择可保存。
- 自动保存后刷新可恢复。
- 草稿预览显示本地预览提示，robots 为 noindex,nofollow。
- 本地发布后同源前台可阅读；未来定时文章未提前公开。
- 修订记录可恢复到编辑草稿，不直接发布。
- 评论提交、审核通过、前台展示完成一轮验证。
- 分类新增与重命名、媒体上传、成员资料新增可操作。
- 批量移至回收站与恢复草稿可操作。
- JSON 导出包含文章和媒体；有效备份可导入，非法文章标识备份被拒绝。
- HTML 过滤去除脚本、事件处理属性和非许可 iframe；许可视频设置 sandbox。
- 1440px / 1024px / 390px 的前台与编辑器检查无页面横向溢出。
- 浏览器测试无页面脚本异常、无本地资源 HTTP 错误。
- npm audit --omit=dev：0 个已知漏洞（本次查询时）。

## 边界

当前是可操作的静态原型，不是已部署的多人 CMS。未验证真实登录、服务端权限、云端存储、关闭浏览器后的定时发布、真实多人并发、第三方视频在所有网络环境的播放或正式搜索收录。详细接入要求见 README.md。

回归脚本和截图放在工作区 control-recovery 中，不属于运行依赖。
